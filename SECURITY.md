# Security Policy

## Reporting a Vulnerability or Data Issue

If you discover a security vulnerability or a critical data issue in this project, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please contact the maintainers directly via email:
- james.y.zhang@yale.edu
- faheem.almas@yale.edu
- bryan.kelly@yale.edu

### What to Include
- Description of the vulnerability or data issue
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)
